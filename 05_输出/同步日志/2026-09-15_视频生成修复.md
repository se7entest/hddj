# 同步日志 · 2026-09-15 · 视频生成（gen_video）已修通

## 结论（直接照做）
- Agnes 视频端点 `/v1/videos` 只接受 **`mode="keyframe"`**，且必须带 `first_frame`（尾帧可选 `last_frame`，图片 URL 或 data URL）
- **没有纯文生视频通道**：每条视频都要锚一张首帧图（用定妆照即可）
- `num_frames` 是网关禁用字段（400），时长/规格服务端定（默认 5s、720P）
- 偶发 `503 video_queue_full`，脚本已内置自动重试；免费版另有 429 限速（请求间隔 40-60s）
- 一条视频端到端约 3-5 分钟出结果

## 用法
```bash
python scripts/gen_video.py --prompt "英文动作/镜头描述" --img "05_输出/定妆照/宋栀_v2.png" [--last 尾帧图] [--out "05_输出/E1/P01.mp4"]
```
已用宋栀_v2 首帧实测：提交 → 503 重试 → in_progress → completed → 下载 mp4 成功（977 KB，存 `05_输出/_test/P_test.mp4`）。
