# 「狐渡」短剧大纲（东北出马仙 · 抖音竖屏 · 第一季 27 集）

> 剧名：**「狐渡」**（狐＝胡家报马·胡飞玲，可视化核心符号；渡＝超度，双层：表面度鬼（民俗），实际度人心（主题）。"狐渡"谐音留"糊涂账"的暗味——钱两清、人心自己还，全剧就是一本糊涂账；**不点破、不推"犯浑"**）
> **抖音标签**：`#狐渡` `#狐渡东北出马仙` `#出马仙` `#跳大神` `#胡仙报马` `#民俗悬疑` `#女频灵异`（封面/首刷前置钩子：标题直接点"狐"，一眼进东北仙家赛道）
> 规格：抖音竖屏，每集 1-3 分钟，第一季 **27 集**（E11-12、E16-17、E26-27 各并一集，除拖沓不除卡点）
> 题眼（已定）：**「人心里的鬼，最难度」**（报马口吻：「世上的鬼都好度，人心里的鬼，最难度。」；注：题眼专用"度"，民俗行话"送鬼"保留不用"度"替换）
> 定调：双层不点破——民俗奇观（立堂/跳大神/收池/捆窍）给足，里层一切"鬼事"= 人心贪嗔痴
> **本版要点**：① 季长 30→**27 集**（去拖沓）；② 堂口主人 姑奶奶→**爷爷**（前任堂主；奶奶=在世长辈带她入堂，"爷爷旧案"为暗线/第二季主钩）；③ 婚礼 E21 升级为"当着共同好友的处刑"（圆 E15 栽赃坑）；④ 苗族=**蛊毒之术**，异象为**五毒虫的影子**（非手腕旧饰）；⑤ 赴婚礼动机=了结债务非感情；⑥ 全季无"这只是心理"字面解释，E25-E26 把"人心旧怨"落成实体（仇堂）

## 一、人物轴（最终·已定名）

> 定名：女主**宋栀**（小名"栀子"）｜男一**杨永川**（南方打拼）｜男二·发小**周野**（小名"野子"）｜报马**胡飞玲**｜苗女**吴依依**｜骗子头目**马半仙**｜爷爷**宋德奎**（前任堂主）｜奶奶**刘桂兰**

| 人物 | 设定 | 主题功能 |
|---|---|---|
| **宋栀**（女主，小名"栀子"） | 东北籍，大城市求学，出马主体 | "能扛"的人；逃回东北老家 |
| **杨永川**（男一，南方打拼） | 大城市打拼，**加盟开店**（缺钱不会管、好吃懒做、出去玩）；旅途中/南方遇上**吴依依**（后期娶她） | "贪"的人格化；宋栀借钱又给他打工，他不领情（"嗔"）；动手=嗔到极点 |
| **周野**（男二·发小，小名"野子"） | 与宋栀同村/镇长大，**默默保护她**；不张扬、不控诉、不替她做决定 | "痴"的反面＝朴素的信；第二季感情线，**最终有缘无分** |
| **吴依依**（苗族姑娘） | 杨永川旅途中遇上的南方姑娘；身后带**苗疆蛊毒之术**（五毒虫影子；去魅版＝旧债/旧俗执念，非真蛊） | "煞"的载体；民俗资产（第二季深挖） |
| **宋德奎**（爷爷，前任堂主） | 已故；宋栀家出马这一摊随他去世埋了 | 暗线"爷爷旧案"（周野家是知情方，第二季主钩） |
| **刘桂兰**（奶奶，在世长辈） | 点破仙缘、带宋栀入堂 | 立堂引路人 |
| **马半仙**（骗子头目，姓马） | 假出马团伙头目，第二季**仇堂**的人 | "人心旧怨"实体，栽赃坑的幕后 |

> 对照轴：**男一=南方的钱（贪），发小=故乡的根（痴）**。远是放弃的路，近是回家的路。

## 二、磨难主线（加盟版，已定）

1. 男一搞**加盟开店**（缺钱、不会经营、好吃懒做、成天出去玩），女主**既借钱又去他店里帮忙**（钱+人全部投入）
2. 他出去玩时**遇上苗女**（南方盘），被其魅力/家境/现实利益牵着走
3. 店黄了，钱没了，女主负债＋耗空；男一不领情（怪她管太多/丢人），转头跟苗女
4. **大吵动手（E19）**：男一动手打女主，被发小拦住——"嗔"落到最狠一格
5. 女主**默默回家**（不解释、不控诉）

## 三、三幕结构（27 集）

### 第一幕：放假回家 + 觉醒 + 立堂 + 发小线（E1-E10）
1. **E1-3 觉醒**：E1 大城市怪梦（暗标狐影/缠发）→ E2 返乡（堂口老屋灯自亮）→ E3 奶奶点破仙缘（旧主未走，定立堂）
2. **E4-6 立堂**：学规矩→首次捆窍失控（E5）→胡飞玲定堂（**题眼首现 E6**）；周野初见（E4，"你回来就好"，他"懂"却不声张）
3. **E7-10 春节节点 + 南下**：年三十收池甩鞭（E7）＋跳大神全流程（E8，奇观给足）→ 南下进加盟店（E9）→ 苗女伏笔·五毒虫影子（E10）

### 第二幕：磨难 + 湖南伏笔 + 分手（E11-E19）
- **磨难单元**：E11 借钱＋加码（并一集，不拖）→ E12 苗女再来 → E13 店黄（她负债耗空、他不领情）→ E14 不领情讨账
- **栽赃坑（E15）**：假出马骗子团伙栽赃"她骗钱"（并一集，先造谣后威胁）→ E16 定亲 → E17-E18 分手两格 → **E19 大吵动手＋发小拦住**（发小版题眼"你慢慢送"）

### 第三幕：婚礼心死 + 发小接回 + 开放收尾（E20-E27）
- **E20 赴约动机**：南下赴婚礼——不是为感情，是"把最后两成的债收回来、把借出去的钱和命一起结了"；路上异象密集，喜事成凶第一波
- **E21 当着共同好友的处刑**：男一当众把她的"出马"说成"骗术"（**圆 E15 栽赃坑**）；她不发一言，发小赶到站在身后；尾钩：苗女敬酒，腕下**五毒虫影子**在喜烛光里"爬"，报马「煞是这一屋子人心攒出来的」
- **E22 心死（全季最高潮）**：跳大神＋全程捆窍，她亲自挡煞，救的正是这屋子人心（包括刚羞辱她的共同好友）；报马题眼第二回音，她回「那我自己送」——彻底心死
- **E23 发小接回**：把她接回东北老家，"我等你吃饭"
- **E24 老家·沉默三天（不拖，一集走完）**：留门留饭＋奶奶交底（"你爷爷的事，我骗了你"）＋她第一次自己做规矩（不靠报马）
- **E25 出马·立堂完成＋仇堂亮明**：历经磨难换来的立堂完成；骗子背后**仇堂**（人心旧怨）亮明，递纸条"你爷爷的堂，该还了"
- **E26-E27 开放收尾**：E26 爷爷旧案·浮一页（不全揭）；E27 片尾——男一不狗血释然、题眼第三回音她接住半句、她正式出马落地；三钩收尾（仇堂/爷爷旧案/发小）

## 五、第二季走向（已定，留白不展开）

- **女主 × 发小感情线发展**（第一季"留门留饭/默默保护"升为互明心意）；**最终有缘无分**（无分原因第二季再定：候选=旧案牵连到发小家 / 堂口规矩"弟马不得动堂外情"——与题眼呼应）
- **爷爷旧案**（第一季只浮一页）：发小家是知情方，另一半在发小家；牵出**仇堂**（人心旧怨实体）
- **苗家资产池（去魅版）**：蛊毒＝旧债执念的具象；"赶尸"故事＝没送走的亡人执念＋当年人心旧怨；苗疆"巫"与东北"仙"两套体系南北对撞（奇观＋旧债双线）

## 六、定稿（已定）

1. **两个"狠"点都留，递进不重复**：E19 动手（身体暴力，发小拦住）→ E21 婚礼绝情（当着共同好友的社会性处刑）
2. **题眼回音布局（27 集编号）**：
   - 首现 **E6（定堂）**：报马版，女主当是鬼话
   - **E19（动手后）**：发小版"你心里那些东西，我度不了，你慢慢度"（第二声源，接意不喊题眼）
   - **E22（婚礼心死）**：报马原句第二回音，女主回「那我自己度」——反转
   - **E27（片尾）**：女主主动接住半句
3. **去魅执行线**：全季无"这只是心理"字面解释；异象该吓就吓；报马只半句暗解；E25-E26 把"人心旧怨"落成实体（仇堂/爷爷旧案），让去魅在第二季有实体可抓
4. **用字规范**：题眼/四次回音专用"**度**"（带仪式感）；民俗行话里的"送鬼"（东北出马仙术语）**保留"送"不动**，不混用——"度"才有分量
