# 《狐渡》样板分镜剧本（开季三集 E1-E3 ＋ E22 心死高潮）

> 单集体量：约 **2 分钟/集**（竖屏 9:16）；本样板 4 个"节点集"。
> 规格说明：竖屏短剧，钩子前置（前 3 秒定生死）；每集一个尾钩；报马=胡飞玲（御姐画外音，不出镜，狐影仅关键帧"站身后一帧"）；**挂坠温度**=报马"在不在"的信号器（来=热/沉默=凉）。
> 题眼「人心里的鬼，最难度」：E1-E3 里首次出现是在 E6（定堂），本样板 E1-E3 **先不点破**，只用"怪梦/灯亮/挂坠微热"埋，把题眼留给 E6。E22 是第二回音重头。
> 用字：题眼专用"度"；民俗行话"送鬼/请神送神"保留"送"。

---

## E1 怪梦（约 2 min）· 开季钩子集

**目标**：3 秒内建立"她不对劲 + 有个说不出口的东西缠着她"，留"为什么"。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：黑屏→一双眼睛从暗处睁开（主角宋栀），挂坠贴着她锁骨微热（特写，观众先看到"有温度"再看到人） | 报马画外音（御姐，冷，一句）：「你又"接"东西了。」 |
| 3-20s | **矛盾搭建（含钱债线起手）**：深夜出租屋，桌上冒热气的**廉价泡面**+招聘网站（窘迫立住）；男一杨永川视频请求——**她这边冷暗（泡面/疲惫）vs 他那边亮色（外在环境好）**。杨永川（随意、理所当然）："栀子，加盟店那边还差一点，你先垫我两千？"她看一眼泡面，**停一秒**（习惯性的妥协），不解释直接转账 2000（手机特写，**转账"叮"声略放大**——钱的声音＝底线退让的声音）；他看都没看，顺手敷衍："谢了。你最近别老做那些怪梦，信点科学，别多想。"（**"信科学"+要钱同框，"平庸恶"起手式首立**） | 钱债线 E1 埋（小额垫）→ E9（借钱在先当"免费店长"）→ E11（掏全部积蓄，最后一口）→ E14（赖账）→ E17-18（钱两清收口） |
| 20-60s | **怪梦段**（本集奇观）：夜里，床边站着一个人影（虚焦，看不清脸），话没说完就断；宋栀想走近，人影**往后退进她身后一帧**（狐影首次，一闪即逝） | 报马画外音不接，只有极轻一句：「……」 |
| 60-100s | 醒来：枕上**发丝缠了一夜**（特写，去魅=她其实焦虑失眠，非真狐）；挂坠凉着（报马退走了） | 宋栀自语/内心：「又是这个梦。」她以为是压力 |
| 100-115s | 她摸挂坠（定心动作，冷），决定寒假**回家**（东北老家），跟杨永川随口说"回趟家" | —— |
| **尾钩** | 火车进站方向（她看站台）；报马画外音（第一次正经开口，御姐，带一点"看透"）：「堂口……在等你。」（她没听见/听成幻听） | **下集钩：她到底"接"了什么？** |

**制作提示**：
- 前 3 秒"睁眼+挂坠微热"要**快**，别铺垫；挂坠温度是全季暗号，这里第一次给观众看（热的），后面靠"凉了"制造落差
- 钱债线起手：泡面/起球睡衣的"冷暗"vs 他屏幕里的"亮色"要拉开；**转账"叮"声放大一档**（观众记住这个声音，E11 掏空积蓄时同款音效再现＝回响）
- 她"停一秒再转"是习惯妥协的**第一格**：后面 E11/E14 的妥协全在这个节奏上加重，此处别拍成犹豫纠结，只给一秒，轻而快
- 人影/狐影**全程虚焦、一闪**，绝不出清晰脸（去魅+双层不点破的视觉底线）
- 怪梦段配乐压到极低，靠"静"制造不安，不用廉价鬼音效

## E2 返乡（约 2 min）· 民俗进场集

**目标**：把"老家=堂口老屋"立起来，给"灯自亮"，让民俗从怪梦落到实物。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：东北老家老屋，堂口正房——**灯自己亮了**（特写，烛/灯芯无风自燃） | 报马画外音（轻）：「它等了一整个冬天。」 |
| 3-25s | 下火车：东北小站，**发小周野开车来接**（首登场），**扶着岁数大的奶奶**（刘桂兰）："奶奶非要亲自来接你。"奶奶："这次回来，别像以前那样回去。"（宋栀**一直佩戴**着那只老挂坠——锁骨特写，它是全季报马暗号、**不是这集的新物件**；**香炉＝爷爷旧物，E4 学规矩时才给，不在 E2**） | 台词克制：发小话少、奶奶话慢顿看着她 |
| 25-70s | 回老屋：堂口老屋旧神位、旧堂单（爷爷宋德奎的遗物，积灰）；宋栀从小到大"当迷信"的态度第一次**晃了**（她摸旧神位，手停住） | 奶奶："你爷爷走那年，把这摊东西埋了。可它没走。" |
| 70-100s | 夜里，灯又亮一次；挂坠**无故微热**（第一次"热得有原因"） | —— |
| **尾钩** | 奶奶站灯影里（背影），看着她：「你身上，有东西坐不住。」 | **下集钩：她要立堂？** |

**制作提示**：
- 老屋/旧神位要**土、旧、有年代感**（东北土墙、供桌、香炉），是"奇观给足"的第一落点
- **信物节奏**：挂坠＝宋栀**一直佩戴**（E1 起就有，报马温度暗号）；**老香炉＝爷爷旧物，E4 学规矩时才给**（E2 只出现挂坠，别把香炉提前）
- E2 发小**周野首登场**（开车接站、扶着岁数大的奶奶，话少），比原 E4 更早，给"他什么都知道"暗线多垫一层底
- 挂坠"微热"第一次是**被动发热**（有东西在），和 E1 醒来后"凉"（报马退走）对照

## E3 点破仙缘（约 2 min）· 定调集

**目标**：把"她家出马这一摊"点破，报马第一次"正经开口"，完成第一幕前 3 集的"3 秒定生死"闭环。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：宋栀站在堂口老屋正中，旧主灯影满屋（去魅=她自己心事的投影） | 报马画外音（御姐，笃定）：「不是你怕它，是你欠着它。」 |
| 3-30s | 奶奶带她看清全貌：旧堂单上写满旧事；"你一直当迷信，可你八字里的'仙缘'，爷爷没给你走完" | 奶奶交底一层（不全揭爷爷旧案，留第二季） |
| 30-70s | 报马第一次**正经开口**（御姐，冷而稳，不是鬼话）；她问的不是"愿不愿意立堂" | 报马："你那个他——你还信吗？"（E3 尾钩预埋，回 E1 杨永川） |
| 70-100s | 宋栀沉默；挂坠**烫了一下**（报马"在"得最实的一次，对应她动了真念） | —— |
| **尾钩** | 她望着堂口，没答；报马画外音最后一句（轻）：「不答，也得答。」 | **下一集（E4 学规矩）钩：立堂开始** |

**制作提示**：
- "报马正经开口"是全季第一次让观众"确认有仙家"，音色=御姐冷稳，**别**做成尖细狐媚（我们已定御姐音）
- "你那个他还信吗"这句是**双关钩**：字面问杨永川，暗里问"你还信命运/信堂口吗"，一语双关扣题眼，重看才懂

## E22 婚礼心死（约 2-2.5 min）· 全季最高潮

**目标**：把"仙家管不了有情人"反转为"我自己度"，用一场跳大神+全程捆窍把"能扛全世界、扛不住自己"摔到最疼。

> 前置（已在 E20-E21 完成）：她南下赴婚礼为**了结**（不是感情）；E21 当着共同好友，杨永川当众把她的"出马"说成"骗术"（社会性处刑，圆 E15 栽赃坑）；吴依依敬酒时五毒虫影子在喜烛光里"爬"。**本集直接从"她心死"起跳。**

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-5s | **钩子**：喜堂满屋红光，宋栀站在堂边（挂坠**烫得握不住**），报马画外音（御姐，第一句就点题眼第二回音）：「世上的鬼都好度，人心里的鬼，最难度。」 | 她没接（第一次，她不动） |
| 5-40s | 异象升级（去魅=满屋人心惶惶/怨气旧债的显形，异象唯美化）：烛火齐灭→火苗重新燃起且齐倒向同一方向；喜字自己复原；**共同好友**里有人脸发白、有人躲 | 报马："煞不是她带来的——煞是这一屋子人心攒出来的。" |
| 40-80s | **跳大神·全程捆窍（折中版定稿）**：宋栀走进喜堂中央，**拿起马鞭而不甩**（"我不借神的手了"，beat 可选删），徒手掐诀（手指骨节泛白、渗血丝，下意识捻出"捻香"手势）；**全程捆窍＝生窍压大窍**：身不由己但自己扛，牙关/冷汗/青筋，不拍翻白眼。异象唯美化：满屋红烛火苗齐倒向同一方向；**她每走一步，一烛复燃**（怨气压下去的肉眼进度条），不配阴风音效 | 她救的是"这一屋子人心"，**包括刚羞辱她的共同好友**（反讽顶点：我救过的人，刚还踩我） |
| 80-100s | 异象收束：烛火定、喜字复原、满屋人"落定"（心跳声止）；挂坠**骤然转凉**（报马"退"了，这一棒她自己接住） | —— |
| 100-115s | **心死台词**（本集落点）：报马原句第二回音再响一次（低），她这次**接了** | 宋栀（对报马/对自己，轻，不喊）：「那我自己度。」 |
| **尾钩** | 散场。她没回南方，转身走向"很熟悉的方向"（周野来接，E23）；共同好友里一人追出来，**欲言又止**（第二季传讯人钩子） | **下集钩：周野接她回东北老家** |

**制作提示**：
- 本集是全季奇观顶点，**跳大神段落要拍出"仪式感+痛感"**（鼓点节奏、捆窍时眼神骤变；**不拍翻白眼**——拍牙关/冷汗/青筋，"一个普通女孩在替别人承受地狱"，不是"神棍作法"）
- 痛感特写清单（封顶五个）：骨节泛白 → 渗血丝 → 捻香手势 → 咬牙青筋 → 烛火直立
- **铃响（全季第 3 次、最响）**：跳大神段落中吴依依脚腕红绳小铃与鼓点抢轨，一响即止；她在喜堂一角静立不动（不给脸、不给虫影，只给足部特写+铃声）。响度纪律：全季铃响限 3 次（E10 远景一声 / E21 裙摆下隐约 / E22 本次），此处封顶
- 反讽顶点"救的包括刚踩她的人"——**别拍成她原谅/释然**，拍成"我还在，但不为你们了"（心死不是宽恕）
- 「那我自己度」是全季主题落点句，**必须留白拍**：不解释、不给反应镜头、说完直接黑场切尾钩，让观众自己在后劲里懂
- 挂坠"烫→骤凉"这条温度线是本集的情绪外化主轴，特写至少 3 次（握不住→骤凉→黑场前最后摸一次）
- 民俗底层依据与"窍"状态梯度（E8 上窍 / E22 生窍压大窍）：见 `01_大纲/跳大神与窍_设定参考.md`（制作层文档，概念不进正文）

## 样板自检（这 4 集立住的规矩）

| 规矩 | 本样板落地 |
|---|---|
| 前 3 秒钩子 | E1 睁眼+挂坠热 / E2 灯自亮 / E3 旧主灯影 / E22 满屋红光+题眼 |
| 每集一个尾钩 | 4 集各带下集钩，且 E22 尾钩开第二季线 |
| 报马御姐音 | 4 集画外音全按"清冷笃定"，无狐媚 |
| 挂坠温度信号 | E1（凉）/ E2（微热）/ E3（烫一下）/ E22（握不住→骤凉）——全季温度线开跑 |
| 去魅不点破 | 人影/狐影全虚焦；异象都有"人心"暗解但不写明 |
| 题眼 | E1-E3 只埋不点破（留给 E6）；E22 第二回音重头 |
