# 《狐渡》分镜 E4–E10（第一幕中后段 · 按样板规格铺开）

> 规格沿用 `狐渡_样板分镜_E1-E3_E22.md`：竖屏 9:16，约 2 分钟/集；前 3 秒钩子；每集一个尾钩；报马＝御姐画外音不出镜，狐影仅关键帧一闪；挂坠温度＝报马信号器（来=热/沉默=凉）。
> 用字：题眼专用"度"；民俗行话"请神送神/送鬼"保留"送"。
> 信物节奏提醒：**老香炉 E4 才给**（爷爷旧物，E2/E3 只有挂坠）；报马香＝香炉第五支（供护身报马·胡家）。
> 本段四大件：E4-5 学规矩（喜剧+失控）/ E6 立堂（题眼首现）/ E7 收池甩鞭（名场面）/ E8 全流程跳大神（"形"，扣 E22 的"骨"）/ E9-10 南下+苗女伏笔。

## E4 学规矩（上）（约 2 min）· 喜剧+仪式感集

**目标**：把"堂口规矩"立起来（称谓体系），给"领香炉"仪式，喜剧感落地但不闹；发小"欲言又止"垫一层暗线。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：旧香炉（铜/陶、旧到带豁口）被奶奶从堂口柜子最里层端出来，吹掉浮灰——特写那撮灰 | 报马画外音（轻，御姐）：「它，等你领了三年了。」 |
| 3-40s | 堂口老屋学规矩：奶奶教称谓（小花童/报马香/捆窍禁忌），**喜剧拍法**：她念错行话，奶奶不说话、就看着她（东北长辈的分量感）；纠正后她再念，念对了，奶奶才动一下 | 奶奶（慢、顿）：「立了堂，欠的就要还。」 |
| 40-70s | **领香炉**（仪式 beat）：她把香炉供上，点报马香（第五支），火苗**立住不晃**（香烧得好＝报马接了、有吉）；她点香时**手指下意识捻出捻香手势**（人物小传暗号，第一次给） | —— |
| 70-100s | 村口，发小递东西给她（一袋刚出锅的烧饼/暖手壶），"你回来就好"，不多话；他**回头看了一眼堂口老屋，欲言又止**（他"懂"，不点破） | —— |
| **尾钩** | 她拎香炉回家，挂坠**微微热了一下**（报马"接了"香，确认在场）；报马画外音一句：「领了，就是你的。」 | **下集钩：她第一次试捆窍，会出事** |

**制作提示**：
- 喜剧感靠"**奶奶的不动**"（不说话、就看着）出，不用罐头笑声、不用夸张表情——喜剧和仪式感要长在同一个画面里
- 领香炉是本段**信物交接**的关键帧：香炉进她手里，之后她走到哪香炉跟到哪（E16 锁进抽屉才有分量）

## E5 学规矩（下）＋首次捆窍失控（约 2 min）· 第一幕第一个"疼"点

**目标**：给"失控"但去魅——不是附体闹剧，是"别人的话从她嘴里出来"；发小"只扶住、不声张"立人物。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：宋栀站在堂口中央，**身形一僵**，抬头——特写：她眼睛里的光瞬间"老了"（换了腔） | 她（旧主的腔，慢、发沉，不像她）：「堂口……封了，怎么又开了。」 |
| 3-35s | 首次试捆窍（E4 教的规矩里捆窍禁忌：小花童阶段**不该**捆窍——她因焦虑失眠提前试了，**失控的原因自己埋**）：她越念行话越不受控，声音彻底变成旧主的腔，手指在**掐不存在的印** | 报马画外音不接话，只有轻一句：「……轻点。」（越疼越不给，留白） |
| 35-70s | 失控收束：她"回"来了，愣在原地；发小闻声赶来（他话永远比动作慢半拍：先沉默，再上手**扶住**她，不声张、不围观，就把她带出门透气） | 出门后她只问一句：「我刚才说什么了？」他：「你该记的，你自然记得。」（他"懂"的分寸，不点破） |
| 70-100s | 夜，挂坠**烫得握不住**（报马来得最急的一次）；她低头看香炉——报马香的火苗**断了一秒又续上**（信号：出事了，但报马压住了） | —— |
| **尾钩** | 报马画外音（御姐，笃定）：「乱了。定不下来，是因为你没立堂。」 | **下集钩：立堂，E6** |

**制作提示**：
- 失控＝**换腔不换体**：不拍翻白眼、不拍肢体抽打（那是 E22 的反面教材，痛感特写清单已定）；本集的"失控"全靠**声音和眼神**
- 发小"扶住不声张"要拍足 3 秒以上——这是"痴的反面＝朴素的信"的第一次纯动作呈现

## E6 立堂 · 胡飞玲定堂（约 2 min）· 题眼首现集

**目标**：立堂仪式完成，胡飞玲定名定堂；题眼原句**第一次出现**（当轻的给，重口留给 E22/E27）。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：堂口摆正，新堂单铺在供桌上（爷爷的旧堂单压在最底下，积灰），红烛点上 | 报马画外音：「今儿，立堂。」 |
| 3-40s | 立堂仪式：上表、请神、定名——报马锁定**胡家·胡飞玲**（护身报马）；仪式里宋栀全程规矩、稳（E4-5 学的都在用），奶奶在外屋看着不说话 | —— |
| 40-75s | **题眼首现**：报马画外音（御姐，冷而稳）：「世上的鬼都好度，人心里的鬼，最难度。」她当是**行话/鬼话**，心里划过去，没接（第一次"没接"，观众第一遍记住这句话，第二遍才懂是说自己） | 她低头看堂单上"胡飞玲"三字，手指在名字上停了一下 |
| 75-100s | 定堂成：挂坠**热得握不住**（全季温度最高点之一），她攥着挂坠深呼吸；**狐影在她身后一帧**（不缠发、不贴身，"在场"，不给脸） | —— |
| **尾钩** | 报马画外音（句尾往下收，笃定）：「立了堂，欠的就要还。年三十，坟圈子，甩鞭。」 | **下集钩：E7 收池名场面** |

**制作提示**：
- 题眼原句要**轻着给**：报马说一句就过，不加重音、不切反应镜头——题眼的分量在回音（E19/E22/E27），首现只是"埋下第一颗"
- 立堂仪式的"请神送神"行话全部保留"送"字（铁律 1），本集不出现"度"字行话

## E7 年三十 · 收池（甩鞭）（约 2 min）· 名场面集

**目标**：全季第一个大奇观——坟圈子甩鞭，"鞭到自己该停处自己停"；男一南下旧地的观念第一撞。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：雪地坟圈子，她把马鞭抡起来——**鞭梢停在脸前三寸，自己不动了**（侧身剪影+慢动作） | 报马画外音（一句，短）：「有等的。」 |
| 3-35s | 收池全流程：甩鞭、请神送神行话、宋栀全程"形"在"稳"（她第一次在堂外做仪式，奶奶在远处看着点头）；雪、红烛、鞭影三条线交叉拍 | —— |
| 35-70s | **男一南下旧地撞**：杨永川从南方来看她，看见坟圈子甩鞭，脸白了一瞬，拉她：「别闹了，跟我南下，帮你管店，钱我还干净。」——观念第一撞（他不信+急着想带她走），她没答，只看着鞭停的方向 | 他（算账的手，翻手机）：「那边一个月能挣你这边一年的。」 |
| 70-100s | 她回屋，挂坠**忽冷忽热**（定不下来，和后来的 E12 同型信号，提前给一次）；香炉报马香的火苗**歪着烧**（有吉里有凶，行话：事没完） | —— |
| **尾钩** | 她再看一眼鞭停的方向——**有个人影站着，没散去**（虚焦无脸，一闪） | **下集钩：大初一，那家人上门了** |

**制作提示**：
- "鞭自己停"是本集奇观顶点：**鞭停的那 1 秒不给任何解释**（去魅：人影/鞭停都是"人心"的显形，不点破）
- 男一撞戏保持"**算账的手**"（数钱/翻手机的细节不能丢）——他的恶是平庸的，越顺手越可怕

## E8 大年初一 · 第一次完整跳大神（约 2 min）· 奇观"形"集

**目标**：全流程跳大神（鼓/马鞭/请神送神）了结村上一家的事，堂口在村里立住；**本集拍"形"，给 E22 拍"骨"留空间**。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：鼓点第一响，马鞭扬起——特写她**眼神骤变**（上窍开始，冷厉进来了） | 报马画外音（第一次不给她递词，只一句）：「看你的。」 |
| 3-40s | 跳大神**全流程（形）**：请神歌（唱词保留行话，"送"字全）、马鞭、身段、火堆——她**上窍**：声线/身段/眼神变了，但事完**还有知觉**（会累会虚，蹲下去喘） | 村里人围了一圈，有人跪了——"堂口立住了"的实证 |
| 40-70s | 散了事：她蹲在火堆边，手在抖，发小递来一杯热水（"话比动作慢半拍"again）；她喝完只说：「下次这种，别让我一个人扛。」（她在**学规矩的人**视角，还在攒经验） | 奶奶端着一碗炖菜出来（东北家常味，发小"做菜表达"的镜像，先垫一层） |
| 70-100s | 夜里，堂口她一个人复盘（她开始记"事"——专业感建立）；挂坠**温的**（报马在场但沉默，满意式的不出声） | —— |
| **尾钩** | 报马画外音（低声，御姐，第一次带"急"）：「下一个要还的，是你自己身上的。你南下帮他，就欠着了。」 | **下集钩：她到底去不去南下** |

**制作提示**：
- 本集跳大神拍**"形"（民俗奇观）**：鼓点节奏、马鞭甩动、火堆、围观的人——是"东北出马仙赛道"的定集；**E22 拍"骨"（去鞭手诀+痛感）**，两集对照不腻（间隔 14 集）。状态差异见 `01_大纲/跳大神与窍_设定参考.md`（E8 上窍 / E22 生窍压大窍）
- "报马第一次不递词"（「看你的」）是本集暗线：全季报马"越不给越重"，此处开始收紧

## E9 南下 ＋ 进加盟店（约 2 min）· 换地图集

**目标**：换到南方城市场景，她是"免费店长"（借钱在先），"用规矩处理店里怪事"给一小格，立"她信我的命"的底色。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：南方城街景（霓虹/店招），她拎着**香炉**过街——一炉东北旧香炉撞进南方霓虹里（画面反差的钩子） | 报马画外音（轻）：「南边，风硬。」 |
| 3-40s | 进加盟店当"免费店长"：她干活、对账（**反位**：他算账的手 vs 她理账的手，同框拍——视觉化的"他信钱、她信命"）；生意稀，他三天两头出去玩，她一个人顶 | 他（打电话）：「那边有个人脉，晚上过来。」（又"出去玩"，人设一笔） |
| 40-70s | **用规矩处理店里怪事（轻，一小格）**：收银对不上、监控糊了——她没慌，**手指捻香**（暗号），低低一句行话"先别动，我看一眼"，火苗立住那几秒，账**自己对上了**（去魅：其实是她自己盘出来错的，但画面只给"她看了"，不解释） | 他路过撞见，皱一下眉，没多话（"信科学"第二笔） |
| 70-100s | 夜，她在仓库清点库存，挂坠**凉着**（报马在南边"不常给"——地域越远越不给，温度线暗读）；她摸挂坠（定心动作），没说话 | —— |
| **尾钩** | 他回来，手机举着：「碰见个湖南的姑娘，人可好了，说来店里坐坐。」 | **下集钩：苗女进店，E10** |

**制作提示**：
- "账自己对上了"那格**不给超自然画面**（不拍虫影/光影），全靠"她捻香的手指特写＋账本数字跳一下"——去魅不点破的样板拍法，后续所有"她看了就没事了"的戏照这个拍
- 香炉过街的 3 秒钩子是**全剧视觉母题**：旧香炉×新霓虹，重看才懂是"她把自己整个旧家搬走了"

## E10 苗女伏笔（湖南苗女 · 蛊毒）（约 2 min）· 伏笔启动集

**目标**：苗女进店，南方盘入戏；"五毒虫影子"首次给（不给足部特写，铃响·第 1 次先建"声音"通道）。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：店门"吱"一声开，逆光里一个**南方盘**坐进店里（裙摆铺地，坐姿、口音、发饰全部是"另一个体系"） | 报马画外音（轻，御姐）：「来了。」 |
| 3-35s | 苗女坐店上（南方盘），不说话，就坐；她腕上缠**细绳**，绳下隐约**五毒虫的影子**（蛊毒视觉，去魅=旧债执念非真蛊）；宋栀"先别动，我看一眼"（专业口吻），两人**互相打量**（南北两套体系第一次同框，不冲突，各守各的） | —— |
| 35-70s | 她（宋栀）问报马：「什么东西？」报马不答（第一次"不给"，越重越不给）；挂坠**热了一下**（报马"在场"的警告） | 报马（轻）：「那姑娘身上，有点东西。」（E10 首给，重口留 E21） |
| 70-100s | **铃响·第 1 次（声音暗号首建）**：苗女起身离开，脚腕**红绳小铃**在远景里带出一声轻响（**只给声音、不给足部特写、不给虫影**——足部特写留给 E21 敬酒那一格）；她回头看门口，门已经关了 | —— |
| **尾钩** | 夜，旧主灯影再现（虚焦）；报马画外音（急了一点）：「年关的鬼最饿。你欠着的，它要收。」 | **下集钩：E11 借钱加码** |

**制作提示**：
- 苗女**递着给**（人物小传铁律）：E10 虫影＋铃响（声音首建）/ E21 足部特写＋敬酒"喝点" / E22 铃响全季最响——三格递进，别提前给足部特写
- 苗女全程**不超过 3 句台词**（她人设=话极少），本集一句："我看看你们这。"（越淡越渗人）

## 本段自检（E4-E10 落地的规矩）

| 规矩 | 落地 |
|---|---|
| 前 3 秒钩子 | E4 香炉吹灰 / E5 身形一僵换腔 / E6 立堂红烛 / E7 鞭停脸前三寸 / E8 鼓点＋眼神骤变 / E9 香炉过街 / E10 南方盘坐店 |
| 每集一个尾钩 | 7 集各带下集钩，E8 尾钩是"南下欠债"的提前埋（扣 E11-E14） |
| 报马御姐音 | 全段画外音"清冷笃定"，且开始**收紧**（E8 首次不递词，E10 首次"不答"） |
| 挂坠温度 | E4（微热）/ E5（烫得握不住）/ E6（热得握不住，全季高点之一）/ E7（忽冷忽热，提前给一次）/ E9（凉着，越远越不给）/ E10（热了一下，警告） |
| 去魅不点破 | 人影/狐影/灯影全虚焦；"账自己对上"不给超自然画面；虫影只给影子不给虫 |
| 题眼 | E6 首现（当轻的给），E19/E22/E27 回音不动 |
| 信物节奏 | 香炉 E4 领（此后不离手）/ 铃响 E10 首建（声音，不给足部特写） |
| 两集跳大神对照 | E8 形（全程、上窍）/ E22 骨（去鞭手诀、生窍压大窍），见《跳大神与窍_设定参考》 |
