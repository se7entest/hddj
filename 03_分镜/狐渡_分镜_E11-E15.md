# 《狐渡》分镜 E11–E15（第二幕高压期 · 磨难+栽赃）

> 规格沿用样板：竖屏 9:16，约 2 分钟/集；前 3 秒钩子；每集一个尾钩。
> 本段任务（用户定调）：**打磨"用规矩处理怪事"的爽感（E11-E14 轻给）＋ 憋屈蓄力（E15 封顶）**——爽是给憋屈蓄力的，爽点越稳，E15 栽赃摔得越疼。
> 全段原则：**爽感给"她看事准"，不给"她赚翻"**；每一分爽都在为 E15/E21 的翻脸垫砖。报马从 E11「账，你自己算」起开始**退让**（E11 首次说人话），越痛越不救场。
> 挂坠温度线：E11（凉）/ E12（**忽冷忽热、定不下来**＝情绪外化定集）/ E13（凉）/ E14（凉三日，报马沉默）/ E15（骤热＝报马在场警告）。

---

## E11 借钱＋加码（约 2 min）· 债务阶梯第三级＋爽感首格

**目标**：她掏全部积蓄（债务阶梯：E1 小垫 → E9 店长 → E11 最后一口）；他加码"大机会"（人骗她，去魅非鬼）；给第一格"看事爽点"。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：她打开自己银行卡，余额特写——**四位数**（她最后的钱） | 报马画外音（轻）：「最后一笔了。」 |
| 3-30s | 加盟店缺钱"补一轮"：他算账的手（翻手机对账，E1 同框手法再现），开口："就这一轮，过了这关就翻盘。"她看着自己的余额，**停一秒，转账**（转账"叮"声再现——E1 同款音效，回响定音；量级比 E1 大得多，数字特写） | 她从 E1 起就在往外掏，这次是最后一口 |
| 30-60s | **爽感首格**：店里闹"邪"（收银对不上/常客莫名退货），她"先别动，我看一眼"，捻香（暗号），两分钟给出解法——解法**偏偏是他不会想到的**（用规矩算出"哪批货压了哪个人的财路"），店里人安静看她 | 他撞见，第一反应不是"你行"，是皱一下眉（"信科学"第三笔，同框不对话） |
| 60-90s | 同集内"加码"：他接个电话回来，笑："大机会来了，再垫一笔。"她直觉不对（挂坠凉着、香歪烧——去魅：人骗她加码，非鬼），开口"我全给了，我没了"，他只来一句："那你再想想办法。"（不承认上一笔，加码的话术） | 报马只说人话（全季首次）："账，你自己算。" |
| **尾钩** | 夜里她一个人翻账本（他背着她记的"他欠我的"本，纸面特写）；报马画外音（轻，不再劝） | **下集钩：店里的怪事，越闹越大** |

**制作提示**：
- **爽感的天花板**：她"看事准"给足，但**不让她赚到钱**——这格她只是"看明白了"，钱一分没进她口袋（观众记住这个憋屈，E15 才疼）
- 转账"叮"声：E1 是 2000 的小"叮"，E11 是全积蓄的大"叮"——**音效升级＝情绪升级**
- 报马"账，你自己算"是全季首次说人话（人物小传原句），说完立刻退——此后报马只给信号（挂坠/香），不给话

## E12 苗女再来（约 2 min）· 情绪外化定集（挂坠忽冷忽热）

**目标**：苗女再出现，男一往她那边跑；挂坠"忽冷忽热、定不下来"＝她情绪的外化（全季温度线的复杂态首格）。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：挂坠**忽冷忽热**——她手心在抖，镜头给挂坠在掌心的特写（温度不定，画面用她手指的微颤来呈现） | 报马画外音不给话，只有极轻一句：「定不下来的，不止它。」 |
| 3-30s | 苗女再进店（南方盘，同 E10 规格；铃响不给，只给虫影爬了一下）；他送她走，回头对她："下个月盘个新铺，我和她弄。"（**人开始往苗女那边跑**，第一格） | 她"先别动，我看一眼"——给他看事（信命的最后一格主动，之后她不再替他看） |
| 30-60s | 店越来越空（货架特写：空位一个比一个多）；她一个人守店，夜里在店门口烧报马香（南方巷子里的一炉东北香，反差画面；火苗**定不住，晃**） | —— |
| 60-90s | 她给他打电话说店里的事，他："你自己看着办。"（信钱人设：店=他的钱，事=她的命，他只管钱）；她挂了电话，把"他欠我的"账本翻到新的一页，**这页写了三个字："人心。"**（她还没看懂的债，先记上） | 挂坠凉着（报马不替她定，她自己定不下来） |
| **尾钩** | 报马画外音（轻）：「他和你不一样。他信钱。你别拿命，去称钱的分量。」 | **下集钩：店黄了** |

**制作提示**：
- "忽冷忽热"拍法：**不给温度计，给手**——她握挂坠的手指节奏（握紧→松开→再握紧），观众自己读出"定不下来"
- 南方巷子里烧报马香是**本段视觉母题**（E9 香炉过街之后第二格）：东北旧信物 × 南方霓虹小巷
- "人心"两个字是**她自己记下的账**（人物小传：她度得了天下鬼，度不了心里那一支——E12 她还没看懂，先记上，E18 那句"人心你自己还"就是这本账的收口）

## E13 店黄（约 2 min）· 第一次真正吵

**目标**：店黄、钱没了、她负债耗空；他不领情，怪她管太多；**第一次真正吵**（吵的是"责任"，不是感情——感情他早就没有了）。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：卷帘门"哗啦"拉下，店招被摘下——特写：新店铺名已经写好了，是苗女的名字（她没资格看那个名字，观众看清，她没看清） | —— |
| 3-30s | 结账：货卖不动、钱没了、她背的库存（E11 尾钩）全成了她的；他一句话不认账："你管得太宽了，店是这么被你管黄的。"（**不领情首爆点**：她掏了全部积蓄，他怪她管太多） | 她第一反应是**沉默**（抽离型），第二反应才开口："货是你的，我看的每一单，账都在。"（E15 保险丝同型：不自证清白，只翻账） |
| 30-70s | **第一次真正吵**（吵责任不吵感情）：他"大机会"（E11 加码那个）黄了，他嘴硬："那行不行，谁说得准？"她："你连自己亏了多少都记不住。"（戳中算账的人——他**说不上来具体数字**，这是他全剧唯一一次露怯，快给 2 秒） | 挂坠骤凉（报马退场，这事报马不碰——"你自己的因果"） |
| 70-100s | 她收拾行李（新学期回大城市）；打包的是**自己的东西**，店里她没拿一样 | —— |
| **尾钩** | 她给老家发小打电话，只一句："我挺好的。"（电话那头，周野"嗯"了一声，没挂，也没多话——他信她说的，他没拆穿；"信"的第一格兑现） | **下集钩：他在南方赖着讨账** |

**制作提示**：
- "她没看清、观众看清"的钩子：**苗女名字那 1 秒不切她反应**，直接切走——观众替她记住了，这集尾她还不知道
- 他"说不上来数字"的 2 秒露怯是本段**第一格爽点**（给观众一口气），但只给 2 秒就切她，别拍成她赢了——她输的是整盘棋，这格只是他没出干净
- 电话尾钩"我挺好的"：**她报喜，他没拆穿**（周野"信"的兑现方式不是"我信你"三个字，是"他信她说的"——拍沉默，不拍台词）

## E14 不领情（约 2 min）· 全剧男一最狠一句

**目标**：她赖着讨账，他往苗女那边靠；**"信我的命，别拿你那些东西管我"（人物小传：全剧他最狠一句，扣死"信科学"人设）**。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：她站在他的新住处门口（南方城中村，和他"信科学"人设反差的穷亮），手里拎着**账本**（她自己的那本，"他欠我的"页页有数） | 报马画外音不给话，只有挂坠**凉了三日**（报马沉默的定集：这事报马从头到尾不出场） |
| 3-30s | 讨账：她把账本一页页翻给他看（**翻页的特写，数字特写**——她用他的语言（钱）跟他说事），他一句不接，手机举着，人已经出门："我和她，今晚看铺子。"（往苗女那边跑，第二格：店没了，人还在跑） | —— |
| 30-60s | 她堵他："我借你的，我出的命，你总得有个说法。"他停了一下，**不看她，先看手机**（说谎的暗号，人物小传），然后：「信我的命，别拿你那些东西管我。」（**全剧他最狠一句**——"实病虚病错位伤人"：她真在救这个家，他当她装神弄鬼；他不承认他不懂，只说"你那些东西"） | 她没接这句话（这句话 E15/E19 会要她命） |
| 60-90s | 她转身走，走到巷口，**挂坠凉着，她摸了一下**（定心动作，全季"她信着"的最后一格，E16 锁香炉前） | 报马画外音（轻，只一句）：「你给他的，他不认。你欠他的，他收下了。」（**半句暗解**：他不还她，他欠她的——账是她自己的心，没人认） |
| **尾钩** | 她回住处，把"他欠我的"账本最后一页翻过来——**背面是空白的**（她还没敢写"人心"那三个字收口，E18 会写） | **下集钩：E15 栽赃** |

**制作提示**：
- "信我的命，别拿你那些东西管我"是本集**全剧分量最重的一句台词**：不加重音、不切反应镜头，他**说得很轻**（轻＝他根本不当回事，这才是最狠的）——她这边给 1 秒静默
- 账本翻页特写是全段视觉母题的**收口格**（E11 记"人心"→E14 翻给谁看→E18 两清收口）；翻页声音（纸的脆响）要干净
- 挂坠"凉三日"是本段报马最重的一次退场——**越痛越不给**（全季报马"越不给越重"的顶点之一）

## E15 误会＋栽赃（约 2 min）· 憋屈封顶（合并原16-17）

**目标**：假出马骗子团伙借"她看事"栽赃（收钱反咬），城里传开"她骗钱"；男一那边也听到，误会封顶；同集内团伙头目（马半仙）一句狠话，**栽赃+威胁两集戏压一集**。

| 时间 | 画面（竖屏） | 内容 |
|---|---|---|
| 0-3s | **钩子**：店里，一个"客户"把钱拍在柜台上，镜头给那沓钱——**钱上有红字"出马"**（马半仙团伙做局用的记号钱，特写 1 秒，观众第一遍没看懂，E25 回看才懂） | 报马画外音（急，全季报马唯一一次带"急"）：「别收。」 |
| 3-30s | 团伙做局：收她"看事"的钱，第二天反咬"她骗钱"（她明明"看事准"（E11 爽感），但账是**别人造的**——她拿不出那笔交易的任何凭证，因为她没记那笔，马半仙记了）；城里传开，先是店门口议论声（不拍脸，只拍手和嘴），再是他打来电话，只一句：「他们都说你骗钱。」 | 她没接电话（抽离型），把"他欠我的"账本拿出来，**开始补那笔她没记的交易——补不上**（因为她没在场，马半仙先记了） |
| 30-60s | 她翻自己的账本逐笔对（**爽点的最后一格：她用账本自证**），翻到那笔——**账本上干干净净，没有那一笔**（她没收过，但没人信"没收过"）；她对着账本坐了很久，**手在抖**（这是全季她第一次"看事"帮不了自己——她看得到别人的事，看不到自己的冤） | 挂坠**骤热**（报马在场警告：这事报马不碰，报马只给信号） |
| 60-90s | 马半仙上门（不进店，店门口一句）："再敢看事，就让你看看什么叫真出马。"（威胁）；他（男一）打来第二个电话，她这次接了，他："你真能看事，怎么看不住自己？"（**他信了谣言，不替她问一句"你有没有收过"**——信科学人设的最后一格：他信"大家都说"，不信她） | 她没解释（解释不了，因为全是人心） |
| **尾钩** | **保险丝（定稿）**：她对着店门口议论的人群，平静一句（不自证清白，只破话术，**信人设的"账本"逻辑**）："我看的每一单，账都在。不信的，自己翻。"（说完转身进店，门"啪"一关） | **下集钩：E16 定亲** |

**制作提示**：
- **栽赃的核心是"她看事准却证不了自己"**——E11 给她攒了多少"她准"，E15 就摔多少"准的没用，因为账是别人造的"（爽点蓄力全在这里收回）
- 红字"出马"记号钱（钩子那 1 秒）是**E25 回看的料**：观众重看 E15 才懂那沓钱是马半仙做局的信物，**第一遍不给解释**（去魅）
- 报马全季唯一一次"急"（「别收」）：给在 0-3s 钩子里，**只一句**，之后报马再没带过急——"越不给越重"的顶点之一
- 保险丝台词（已进逐集细纲v2 E15 行）：**"我看的每一单，账都在。不信的，自己翻。"**——她不自证"我没骗"，她让对方去翻账（她的账本是她唯一的武器，也是她全剧"能扛"的物证）
- 男一"你真能看事，怎么看不住自己？"（尾钩台词）：**不接、不解释**——这句话的重锤留给 E21（"骗术罢了"当众坐实）和 E22（"那我自己度"）

## 本段自检（E11-E15 落地的规矩）

| 规矩 | 落地 |
|---|---|
| 前 3 秒钩子 | E11 余额四位数 / E12 挂坠抖 / E13 店招牌换名 / E14 城中村门口拎账本 / E15 红字记号钱 |
| 每集一个尾钩 | E11 账本翻夜 / E12 报马暗解 / E13 电话"我挺好的" / E14 账本空白页 / E15 保险丝台词 |
| 爽感天花板 | E11 她"看事准"但一分没赚到；E13 露怯 2 秒不给赢；E15 她准但证不了自己（爽全收回给憋屈） |
| 报马退场 | E11 首次说人话（「账，你自己算」）/ E12 不给话 / E13 退场（挂坠骤凉）/ E14 凉三日 / E15 唯一一次"急"（「别收」） |
| 挂坠温度 | E11 凉 / E12 忽冷忽热（定集）/ E13 骤凉 / E14 凉三日 / E15 骤热 |
| 去魅不点破 | 栽赃全程不拍"真仙家"；报马只给信号不给话；"红字记号钱"不给解释（E25 回看料） |
| 保险丝 | E15 唯一一句反击（账本逻辑，不自证） |
